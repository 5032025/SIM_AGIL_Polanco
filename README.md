# Proyecto Calculadora Básica - Prácticas de Calidad

Este repositorio contiene una implementación sencilla de una calculadora en Python desarrollada bajo un flujo de trabajo profesional. Para asegurar la calidad y mantenibilidad del software, se integraron estándares de codificación limpios y una estructura basada en ramas de trabajo independientes. Estas prácticas permiten mantener un código legible, estructurado y libre de inconsistencias estéticas o sintácticas desde las primeras etapas del desarrollo del proyecto.

Asimismo, se implementó el uso obligatorio de Pull Requests acompañados de revisiones de código (Code Review) antes de fusionar cualquier cambio a la rama principal. Esto previene la introducción de errores lógicos en producción, fomentando la integración continua y evitando el anti-patrón del “Big Bang”. Como resultado, se reduce drásticamente el retrabajo y se optimiza el tiempo de entrega al validar y corregir los componentes de forma temprana y colaborativa.
